
# NoteDeck 📝

An offline-first desktop notes application built with Electron.

### ✨ Features
- Rich-text editing and image support
- Export to PDF, DOCX, JSON, HTML, Markdown & TXT
- Offline-first with local storage
- Native printing support

### 🛠️ Tech Stack
Electron, JavaScript, HTML5, CSS3, Node.js, localStorage & IndexedDB.
